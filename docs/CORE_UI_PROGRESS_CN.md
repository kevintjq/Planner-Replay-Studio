# 核心 UI 修正记录

更新：2026-11-27。此次保留四工作区、源数据和既有功能，按实测反馈修复公共控件与核心操作。

- 工作区使用蓝色选中背景；普通面板用分隔线 token，输入框保留独立可辨边界。Layers 与 Inspector 恢复清楚的标题层级；亮暗模式共用布局及尺寸。
- 图层列表、画布选中和时间轴选中会定位到对应 Inspector。普通图层使用柔和选中背景，主要执行按钮继续使用强调色。
- 编辑输入框或文本区时，Space、左右键和撤销/重做留给文本编辑，避免全局回放快捷键截走输入。
- 左栏提供 RViz 快速导入，Ctrl+Shift+I 打开配置选择器。支持直接拖入单个 RViz/YAML、Bag、旧项目或多段视频；混合多文档和非本地 URL 拒绝导入，防止异步加载相互覆盖。
- 搜索下拉打开时定位已选项；上下键使当前项进入可视区域，Enter 选择，Esc 关闭；无匹配项时 Enter 不选择过期项。下拉右对齐，减少窄 Inspector 右侧溢出。
- Topic Inspector 在 216 px 最小侧栏宽度下纵向排列时间、话题和读取操作；消息区支持阅读、选区及明确空状态。原“1 帧”实际为 1/60 秒，现以提示明确实验时间步长，不冒充源视频逐帧。

组件回归使用真实 Qt Quick 控件及键盘事件，检查已选话题定位/Down/Enter、无匹配项/Enter/Esc，以及亮暗模式下窄侧栏直接子控件几何。测试中的消息对象仅用于布局，不用于宣称真实 ROS、插件或数据验收。

2026-11-27 本地 Qt 6.8.3、Basic 样式、offscreen 组件测试通过 6 项（含初始化/清理）；日志位于忽略目录 `build-native/core-ui-component-results.txt`。公共组件与 Main 的 qmllint 无语法错误；C++ 全局上下文类型仍有静态解析警告。

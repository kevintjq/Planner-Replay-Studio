# UAV Studio 增量开发计划

更新：2026-11-27。原始 30 章、科研增量 24 章、实测反馈 15 章和独立图片导出 6 章均有效。
本次发行范围以 [v1.0.0 核心发行要求](V1_CORE_RELEASE_SCOPE_CN.md) 为准。
P0/P1/P2 表示依赖顺序；高级需求继续进入 Roadmap 和独立 PR，不阻塞本次核心发行。

1. 核心 UI：完成四工作区 Apple 风格、Light/Dark/System、控件可读性、内联设置、选择联动、
   键盘输入边界及下拉交互。保持参考 SVG 的布局；保留用户主动浮动时间轴。
2. 核心可视化：真实 RViz Display/Property、按类型/Topic 添加、.rviz 导入导出、TF 跟随、
   独立多视角与共享数据。真实插件后端与现有渲染子集分别标识；原生后端独立时钟不冒充主播放头同步。
3. 核心编辑与输出：精确源 PTS、视频同步、自由画布、时间轴、速度表、视频和单帧图片导出。
   共享解码、渲染和实验时间；完成随机跳转、导出恢复及图片/视频对应帧对照。
4. 核心拖影与交付：真实无人机前景、跟踪/排除/缩略图/撤销，项目新旧后缀、仓库和文件夹命名、
   README、专属图标与安装器。用户素材只读，缺少真实无人机素材时明确记录该门禁。
5. 核心体验版门禁：以上流程完成实际 GUI、原生 RViz 对照、完整工作流和稳定性检查后，
   立即提供可安装的预览体验版本及真实运行截图。内部构建/组件测试不能替代 GUI 验收；
   体验版保持预览标识，保留旧版本回退。
6. 当前保留基础曲线、关键帧、距离采样、手动蒙版/配准、适用矢量/混合输出、B站模式、
   字幕/音频/变速等既定核心。APE/RPE/RMSE、AR、高级多实验统计、智能事件/姿态采样、
   高级分割/跟踪、自动论文排版/报告/素材包、更多第三方插件转后续独立分支与 PR。
7. v1.0.0 正式版门禁：完成最新核心矩阵、真实 GUI、安装/迁移、性能、兼容差异与文档证据。
   目标 2026-11-29（星期日），不得降低质量、伪造证据或以截止日期自动发布；高级需求不阻塞本次发行。

当前证据与差距见 [验收矩阵](REBUILD_ACCEPTANCE_CN.md)。不把“构建成功”记成 GUI 或科研功能通过。

最新 P0：按 [四工作区与无数据要求](WORKSPACE_AND_EMPTY_SCENE_REQUIREMENTS_CN.md) 落实独立空场景、
Display/数据源生命周期解耦、离线 .rviz、真实原生工具及透明自动后端管理。
Visualization 采用 RViz 逻辑；Synchronization 聚焦消息/时间；两个创作工作区共用画布但保留专业操作。
Windows 独立安装不强制要求 WSL/ROS/Python；原生插件增强和独立子集能力分别验收。

最新共享架构约束见 UNIFIED_CANVAS_REQUIREMENTS_CN.md：Video Editor / Trajectory Studio 共用一套画布与渲染导出基础设施，分别保存工作区实例/状态。先抽出共享模型宿主接口，再接入缓存的背景/无人机前景/轨迹/端点及科研元素，禁止复制另一套画布。

最新 P0：优先修复真实视频无法鼠标拖动/缩放；共用项目画布变换模型、八手柄、旋转、选择联动、Layout/Camera模式及实际操作录屏，详见 FREE_CANVAS_CORRECTION_CN.md。
同级P0：全部可创建元素真正CRUD，区分图层/片段/素材删除，统一Undo/Redo、依赖报告、资源释放及100次循环实测；详见 ELEMENT_LIFECYCLE_REQUIREMENTS_CN.md 与 ELEMENT_LIFECYCLE_ACCEPTANCE_CN.md。
科研速度仪表盘18章/25项验收同时加入 SPEED_METER_REQUIREMENTS_CN.md；复用完整SI数据、精确时间和自由画布，其他原生RViz/真实无人机前景任务继续并行。

本轮补齐 Trajectory Studio 源帧/累积轨迹图批量和多联图，复用共享批量规划、轨迹合成及图片写入，
实际源视频 4K/8K、区间/采样网格、取消与状态保持已有证据。该工作区科研事件、独立图层/视角、
真实无人机前景提取及长视频仍按上述依赖顺序推进。操作及时间定义见
[轨迹画面导出说明](TRAJECTORY_FRAME_EXPORT_CN.md)。

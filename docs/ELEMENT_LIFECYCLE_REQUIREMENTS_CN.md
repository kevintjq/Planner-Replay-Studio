# 素材及元素生命周期 P0 增量要求

来源：用户2026-11-27实测导入视频无法删除。补充全部此前需求；不得用界面隐藏代替真实删除，不删除任何磁盘源文件。

## 1. 全部元素 CRUD

ROS Bag/Topic/PointCloud2/Marker/MarkerArray/Path/Odometry/TF/RViz配置，实拍/ROS图像/音频/图片/Logo/文字/字幕，主3D/全局/TF小窗，速度表/曲线/指标/图例/Colorbar/放大图/标注，时间轴片段/关键帧/实验事件/拖影采样/排除/统计区间均需创建、查看、更新、删除。能添加不能删除即失败。

## 2. 入口和焦点

画布或列表选中→Delete、图层右键Remove、列表删除按钮、Inspector Remove、Ctrl/Shift多选批删、删除分组。
片段Delete只删所选片段。文本/数值编辑时不误删层；普通删除无频繁确认，以轻量撤销提示替代。

## 3. 三种语义

Remove Layer只删画布实例，保留素材及其他引用。Remove Clip只删选中片段，保留其他片段和源。
Remove Source移除项目素材；若有引用，在当前页明确列影响对象，允许取消或确认移除引用，绝不留悬空引用。
原始文件一律只读，项目删除不删除磁盘科研数据。

## 4. 状态同步

素材/Display/Layers/画布/3D/Inspector/时间轴/关键帧/引用/项目/输出同步；无残留画面、音频、无用订阅、持续渲染、崩溃或重开复活。
必须处理C++对象、解码器、队列、历史点云/Marker、TF/GPU/纹理/缩略图、异步任务及引用计数；共享源最后引用释放才释放，不阻塞主线程。

## 5. 统一历史

Ctrl+Z、Ctrl+Shift+Z/Ctrl+Y。添加/删除/批删/变换/属性/透明/排序/裁剪/关键帧/采样/排除可撤销重做。
完整恢复源、变换、样式、时间和关键帧；批操作一次撤销。

## 6. 素材库

导入/移除/替换/重命名/搜索/分类/多选批删/属性/引用/重链丢失文件/清理未用源；清理只改项目不删文件。
Layer支持添加删除复制替换重命名显隐锁定变换透明排序分组、多选批操作。清空画布保留源。

## 7. UI

Apple布局，亮暗统一，悬停快捷操作、完整右键菜单、Delete、内联撤销提示；常规不弹设置窗口。

## 8. GUI二十项

1导入视频删除、2多视频单删、3层删源保留、4源删引用处理、5磁盘完整、6图片/文字/表/曲线删除、7视角删除、8Display删除、9Bag源删除、10片段删除、11关键帧删除、12拖影采样删除、13批删、14完整撤销、15重做、16预览输出一致、17项目重开保持、18播放中删除稳定、19连续至少100次增删并查资源/状态、20四工作区全部可添加元素具适用入口。

## 9. 生命周期矩阵

每种元素追踪 Add/Edit/Delete/Undo/Save/Export，状态必须根据真实证据填写；任何列缺失不算验收通过。参见 ELEMENT_LIFECYCLE_ACCEPTANCE_CN.md。

## 10. 执行

复用统一C++模型/命令/生命周期，不引入Python运行依赖；实现、实际GUI测试修复后Conventional Commit，继续全部此前任务。

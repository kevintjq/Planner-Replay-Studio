# 拖影图前景提取与共享画布

更新：2026-11-27。真实视频证据、当前统计及未通过项见
`FOREGROUND_ACCEPTANCE_PROGRESS_CN.md`；本说明不代表完整 GUI 验收通过。

## 源数据与提取

应用使用 C++ / Qt / OpenCV 和 FFmpeg，无 Python 运行依赖。跟踪、原始裁剪、采样、
蒙版编辑及导出以实际解码 PTS 时间为依据，不根据平均 FPS 推算帧时间。

固定机位自动背景由实际源视频时间点的原分辨率观测构建：时域中值最多取 24 帧，
参考内存预算为 160 MiB；没有足够观测时使用排除目标框的背景参考。可以改用指定
源视频时间或同尺寸背景图片。底图修补不是实际背景观测，使用时明确显示警告。

定位使用用户框选对象的实际外观、背景差异及 CSRT 辅助。可靠目标外观缺失的帧
记录失败，不将背景纹理作为成功目标。裁剪在跟踪框外保留水平 20%、垂直 25% 的
边界空间，再在原分辨率做背景差分、曝光补偿、自适应阈值、连通区域筛选和羽化。
这不是通用无人机语义分割；遮挡、球网、动态背景和相机运动仍需实际检查。

`foregroundFraction` 是羽化前有效前景像素数占 ROI 的比例，仅用于诊断，不是
分割正确率或科研置信度。非零 alpha 不能代替检查无人机实际内容。

原始裁剪和透明 sprite 共用 96 MiB 缓存预算；超出预算的内容保存在当前任务的
临时 PNG 缓存。预览、改样式和导出复用这些缓存。项目保存源路径、准确时间、
选择框和非破坏性编辑；当前重开项目仍需从真实源视频重建提取缓存。

## 手工修正与失败门禁

内联编辑器提供原图、蒙版、前景切换、画笔、橡皮和恢复自动蒙版。笔画、排除、
单帧透明度和删除引用按源时间保存，支持撤销、重做及项目恢复。移除项目视频不
删除磁盘源文件；清空生成结果不会在重开时凭残留选框自动重新生成。

提取失败返回透明 sprite 并保留原因。合成前重新检查实际 alpha；全部失败、
全部隐藏或所有前景移出画布时拒绝导出，避免背景图冒充成功拖影。
“跳过无效帧”须显式启用，仍要求至少一个可见前景实例。
“仅轨迹线”是独立的用户选择，要求实际可见线段，不能用移出画布的路径通过门禁。

可选相机配准仅估计受限的小幅平移，保留接受和拒绝计数；尚未通过真实抖动、
旋转或移动相机验收，不能据此宣称通用移动相机抠图。

## 共享图层与输出

Trajectory Studio 通过 `CanvasLayerModel::Binding` 复用通用图层状态、选择、
变换、复制、排序和编辑事务。背景、各真实源时间前景、轨迹线、起点和终点是
独立对象，工作区状态保存在 `trajectory_studio.canvas`，与视频画布分开。
样式修改只重绘，不重新提取前景。

预览、PNG、单帧和批量导出使用同一 QPainter 合成；科研文字、图片、箭头、圆形、
矩形与原生拖影对象按同一 z 顺序绘制，支持共同的几何、显隐、透明度和关键帧。
批量导出按每个请求时间计算画布状态，不套用预览时钟或最后跟踪帧的时钟。

PDF / SVG 保留真实轨迹路径、端点圆和文字为矢量；视频前景、背景及图片仍是嵌入
位图。多联图的图像面板目前是位图，标题文字是矢量，不能宣称为纯矢量论文图。
输出颜色由独立样式决定，不随软件亮暗主题改变。

单帧 `exportFrame` 默认 `scope: "canvas"`，继续检查真实 UAV 前景（或用户明确选择
的仅线模式）。`scope: "layers"` 配合 `layerIds: [id, ...]` 只输出所选的原生或科研
对象，保留完整画布坐标和尺寸，不自动裁切到选中边界。此模式可主动输出文字、线或
背景，不将零 UAV 的选择输出描述成成功拖影。空、未知、全部隐藏或移出画布的选择
明确失败；未选择的前景缓存不会阻塞文字或背景导出。

`frameExportReport` 返回 `scope`、`layerIds`、实际绘制 `paintedLayers`、
`composedUavInstances`、时间、尺寸、DPI、成功/错误及 `foregroundGateApplied`。
`cleanForegroundAccepted` 始终为 false：导出成功不等于自动分割已通过视觉验收。
PNG 元数据包含范围和 UAV 实例数，PDF/SVG 元数据标明范围；选中输出仍保持适用
内容的真实矢量。批量选中层输出尚未实现，非 canvas 范围明确拒绝。

`foreground_extraction_test` 的合成图像仅验证失败门禁、源 RGB 保留、曝光与参考
处理；`trajectory_export_test` 验证共享图层、精确时间、多格式、矢量原语及编辑
状态保持。两者不代替真实无人机、完整 GUI 或科研制图最终验收。

# 任意视频帧及科研对比图独立导出

来源：用户 2026-11-27 增量指令；补充此前全部需求。实现与验收逐项追踪，不回滚有效代码。

## 1. 导出范围

Visualization、Video Editor、Trajectory Studio 预览右上角提供相机入口、快捷键和内联设置。
支持完整画布、选中视角、选中图层、所有视角分别导出、批量关键帧。
完整画布保留多算法、多视角、实飞视频、文字、图片、速度表、曲线、颜色标尺、图例、科研标注。

## 2. 画质及格式

使用高分辨率离屏渲染，禁止放大窗口截图。支持 1080P、2K、4K、8K、自定义尺寸和比例、
自定义 DPI 与 300/600/1200 DPI 论文预设、PNG/JPG/TIFF/PDF/SVG、白/黑/透明/自定义背景、
抗锯齿和高质量渲染。适用轨迹、文字、图例、曲线尽量输出真实矢量；点云、视频允许嵌入位图，
必须明确混合内容。检查 GPU 最大纹理及显存，必要时分块。禁止默认软件水印。

## 3. 准确时间及画质恢复

使用播放头准确实验时间，同步点云/地图、TF、Odometry、规划/历史轨迹、相机姿态、视频、
速度表、曲线、算法对比、图层和关键帧动画。离屏流程不得用错时间。导出前恢复代理预览及
快速拖动时的完整精度。输出配色独立于 UI 主题，清除编辑边框、控制点、对齐线和时间轴 UI。

## 4. 批量及科研多联图

时间来源：手动多个时间点、固定间隔、科研事件、指定采样帧、时间区间。
自动生成多联科研配图，(a)/(b)/(c)/(d) 子图编号、实际实验时间戳、自定义命名。
统一尺寸、比例尺、字体和颜色映射范围，用户显式设置时才独立。

## 5. 交互及输出开关

相机按钮采用下拉菜单或 Inspector 内联设置，不创建普通配置顶层窗口。
允许选择文字、速度表、曲线、时间戳、图例、网格、坐标轴、科研标注；支持快速保存快捷键。
复用现有三维渲染、自由画布、论文制图，保持界面响应，全部 C++/Qt、中英文说明。

## 6. 必须实际验收

逐项生成并打开检查：任意时刻完整画布、单视角、多算法、多图层、4K、8K、透明、PDF、SVG、
多关键帧、多联图、随机跳转时间准确性、图片与视频对应帧一致性。
检查真实文件格式、像素尺寸、内容、DPI、透明度及质量；只有文件存在不算验收通过。

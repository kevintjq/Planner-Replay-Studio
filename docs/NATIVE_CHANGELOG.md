# UAV Studio 原生开发变更

## v1.0.0 Core Release · 2026-11-28

本次版本聚焦四工作区必要核心流程。高级科研、AR及非阻塞UI/边界兼容保留后续PR，
不宣称全部RViz插件、任意背景自动分割或全平台认证。最终安装包门禁结果独立记录在
[验收矩阵](REBUILD_ACCEPTANCE_CN.md)；以下GUI和文件证据不代替最终包本机运行。

- C++ / Qt四工作区共用语义主题与Light/Dark/System偏好，内联属性和共享滚动区域保持长属性可达；场景与输出配色独立。
- 视频、轨迹图、单帧和视频输出共用FFmpeg整数PTS与有理数时间基准，保留随机跳转、偏移/双锚点映射及独立对应帧证据。
- 原生RViz属性、.rviz未知字段、TF/多视角和相机Controller随项目保留。真实GUI完成相机Scale 19.25→20、精确播放头不变、保存及D5AB宿主重开两附加视角，并读取真实Odometry消息；参见[GUI验收](VALIDATION.md)。
- D5AB宿主修复Marker消息Header前置常量的布局识别；16项布局回归及真实Odometry明确派生的四类消息46项检查通过。派生兼容性不冒充EGO/SUPER原始规划录制，8C87的33类结构结果仍保留原版本归属。
- Video Editor实际GUI导出8–10秒区间的3840×2160、60fps、120帧H.264视频；实际首帧检查包含已保存画布构图、真实视频和速度表，无编辑手柄。该短片不等于全部帧/音频/长视频性能穷尽验收。
- Trajectory Studio实际GUI恢复六采样/三过滤/三可见无人机的手修项目并输出3840×2160 RGBA图片。源RGB零变化来自此前C++原图/蒙版对照；4秒实例保留真实轻度遮挡，不补画隐藏飞机，4K重采样不宣称创造源细节。
- 安装器使用可信载荷清单、安全同路径升级与旧程序整体备份。当前助手43项保全/拒绝/事务检查通过；最终1.0冻结载荷另以隔离产品身份实际安装，本机原生窗口57/57通过、1481文件SHA匹配，透明PNG、H.264/AAC、实际视频解码编辑、CLI OpenGL三维图片及卸载成功。真实0.1.1完整载荷同路径升级到最终1.0另36/36通过，验证逐文件完整性、旧程序备份、项目/配置/历史保全及升级后布局运行；各项范围分别保留。
- 统一UAV Studio品牌、项目后缀兼容、About/作者/版本元信息、非强制异步更新入口和专属图标。公开Gallery仅含已授权的空Grid/Axes亮色与System深色截图，实验素材继续只读且不提交。

下面开发版本段落保留当时实现与限制，不把历史状态批量改写为本版全部通过。

- 原生属性选择按真实根归属及 view ID 路由，相机属性留在 Camera；8C87宿主已修复纯相机编辑取消同步，20项客户端专项通过，主GUI及机位名称显示仍需复验。
- 修复重开已编辑蒙版项目时，缩略图 URL 早于图片提供器快照发布的竞态；真实 GUI 重开首帧缩略图已复验。
- 真实固定机位素材完成六采样、六自动提取、六帧 Keep/Erase 精修，过滤三个重叠/严重遮挡采样后合成三个真实实例。主任务视检确认 0/3 秒主体清楚、4 秒保留轻度真实遮挡，该素材达到可用候选图；RGB 变化为 0。该结果不外推任意背景，不是自动分割算法改进；精修项目的当前主程序 GUI 恢复及最终导出仍独立验收。
- 当前8C87宿主已独立重跑33类插件结构/547个原生属性/YAML/资源回归，真实数据输出只覆盖5类七图；历史5DA1空机位与客户端删除恢复保留原版本归属。完整渲染、原生RViz对照、透明背景与安装门禁仍按兼容矩阵分别记录。
- 扩展本地日志、崩溃转储及编辑器临时文件忽略规则；私有 Bag、视频与实际几何截图继续排除在提交外。

## 未发行开发版本 · 2026-11-27

基于 main / native-v0.1.1-preview.3。历史发行版保留；本记录不代表稳定版发布或完整验收。

- 核心优先继续推进，科研/AR/B站等全部要求保留后续顺序。新增真正的 Noetic/librviz 进程后端、原生属性树、By Type/Topic、配置保存和实际 OGRE 预览；Header 索引/反向历史恢复与暂停主播放头对接。主画布仍为独立子集；连续原生播放、全插件与原生高分辨率导出尚未认证。
- 视频读取改为 FFmpeg C API 精确 PTS；预览/轨迹/图片/视频共享解码，不按平均 FPS 估算。独立 FFprobe/FFmpeg 对照覆盖 VFR、B 帧、非零 origin、随机跳转及旋转。最新真实视频/图片六个对应帧的编码前 RGB 最大差为 0，有损 MP4 差异另计。
- 主/附加相机的显式 TF、跟随模式、滞后、平滑、独立颜色/显隐随项目保存。真实录包十项 OpenGL 输出通过，随机跳转/隔离/恢复像素差为 0，无 Bag 重载。
- 修复输入焦点的快捷键抢占、搜索下拉键盘选择、窄 Inspector、选中联动与常规属性内联；Qt Quick 组件回归通过，锁屏下不声称手动 GUI 已通过。
- 仓库原地改为 kevintjq/uav-studio，原历史/标签/发行版保留。新 .uavstudio 及旧 .slamfpv 关联、专属安装/卸载/快捷方式图标和隔离安装检查已完成；当前工作目录迁移、完整 GUI/真实无人机/长时性能仍待验收。

以下条目保留此前实施记录；其中旧限制由上面及完整验收矩阵中的最新证据更新。

- C++ / Qt 四工作区，集中 AppearanceManager、语义 Design Tokens、Light/Dark/System 偏好保存。公共输入框、菜单、滚动条、提示框和显式 QML Palette 修复主题绑定；场景及图片/视频输出方案独立。
- 实际退出/重新启动三个进程，Dark → System → Light → Dark 偏好与启动窗口调色板验证通过，重生成四工作区亮暗截图。自动回归同时检查独立子进程恢复及损坏偏好回退 System；操作系统运行中切换外观仍待实测。
- Topic Inspector 内嵌到 Inspector，场景颜色改为内联输入。Topic 和 TF Frame 可搜索，TF 列表来自真实录包。
- 新导入 RViz 完整原文、未知插件属性和兼容诊断随项目保存；未编辑导出保持原文和 BOM，编辑只更新对应显示节点。加入独立 RViz 导出、C++ CLI 往返及可选 Noetic C++ 配置探针，分组/拆分 TF 无法无损表达的编辑明确拒绝。完整原生 RViz 属性编辑与插件渲染仍未完成。
- 已配置但隐藏的 Display 首次加载时同步解码，开关只更新渲染可见性，不重读 Bag、不暂停播放、不重置相机；TF 单个源插件的动态/静态层同步开关。全部配置点云关闭时不再意外显示默认点云。隐藏层缓存仍受现有数据上限约束，大型配置内存待量化。

- 轨迹编辑支持固定间隔/数量/手动采样、多选、单帧 alpha、多段半开排除、拆分、生成范围、撤销/重做及项目保存。纳秒时间用于稳定映射；异步预览、有界缩略图缓存、虚拟模型减少 UI 工作量，长视频性能仍须实测。
- 画布、选中视角和选中图层的独立图片导出，实际提升点云 FBO、完整源视频解码、异步编码、PNG/JPG/TIFF/PDF/SVG、DPI、透明/自定义背景及编辑状态恢复。GPU 超限明确拒绝，尚无分块。

- Trajectory Studio 可导出任意已加载源画面或完整轨迹合成，重算源质量输出，不截取编辑预览；支持高分辨率、DPI 和多格式。新增源视频帧/累积轨迹图批量、手动/区间/采样网格/实际跟踪采样、安全命名、取消清单及科研多联图；请求与实际源帧时间分别记录。导出期间换源及编辑受到控制器保护，项目恢复先取消导出；缺失缓存明确失败。真实提取结果及完整图层拆分仍待验收。
- 新增主题、轨迹编辑、图像编码、批量规划与多联图、轨迹导出回归，并保留旧工作台回归与原生 PNG/MP4 smoke。

# 原生版功能对齐清单

以完整工作台及现有 `.slamfpv` 为兼容基准。正式发行前，原生安装包须通过全部工作流，并在无 Python/Tk 的 Windows 环境启动、运行和导出。原生 CI 安装包供迁移验证。

## 迁移进度

- 项目存储已迁到 C++。可打开项目、跨目录另存、复制项目素材、搬迁重开，并保留尚未迁移的图层和编辑设置。
- 原生回放可从项目启动录包或模拟点云。可读取 Odometry、TF 位姿、外参 JSON 和独立速度话题。合成速度表支持时间区间、量程、拖放与项目保存。主视口有跟随机位和 FPV 预设，附加点云机位支持原项目读取、显隐设置、拖放与保存。
- 多路实拍小窗可读取旧项目的裁剪、偏移、同步锚点及片段。原生界面可添加视频、调整同步锚点，在各视频轨道上裁剪、分割和删段，撤销或重做并另存为项目。
- `.rviz` 配置可导入和保存。PointCloud2、LaserScan、Path、位置话题和 TF 坐标轴可预览。可用静态和动态 TF 将图层转换到已选的固定坐标系。Marker 和 MarkerArray 支持常见的点、线和三角面，话题查看支持录包内的常见 ROS 图像、自定义消息字段和数组分页。
- 命令行可用 `uav-studio-cli inspect recording.bag` 输出话题类型、消息数、录制时间区间及 TF 坐标系关系。可用 `export`、`bag`、`demo` 从项目、录包或内置场景导出 PNG 和 MP4。
- 当前扫描可从 PointCloud2、LaserScan 或 Livox CustomMsg 中选择，按采样时刻的 TF 投影，超过保留时间自动隐藏。选择主点云时复用已解码的当前帧。
- 图片和文字可以叠加、在画布上拖动、在时间轴上编辑显示区间并随项目保存。手动事件标记支持添加、跳转、重命名及删除。
- 布局标记可切换合成、点云全屏、实拍全屏和底片，支持实拍底片缩为小窗。主点云、附加机位、实拍、图片、文字和速度表可添加独立缩窗动画。
- 当前合成画面可导出为 PNG，并可保留透明背景。
- 固定机位拖影已迁移。可框选跟踪目标，调整采样间隔和不透明度，按帧删除与恢复，并以素材原分辨率导出 PNG。
- 原生回放工作台可调用 FFmpeg 输出 1080p / 60 fps MP4，支持选定音轨、分段静音和慢放，可调整分辨率、帧率、画质、超采样和编码器。
- 原生录包回放识别 EGO B 样条和 SUPER 的计划、走廊及目标标记，可跳转到规划事件。支持对比上一条规划与按 CameraInfo 和 TF 绘制相机视场。

完整原始、科研增量、实测反馈及独立图片导出需求均继续有效，不能排除原有着色或渲染参数。当前原生工作台沿用 SLAM 或规划器发布的点云地图；完整原生 RViz 属性、未知配置保留和着色等差距必须逐项补齐。最新证据与未完成项以[完整验收矩阵](REBUILD_ACCEPTANCE_CN.md)为准。

## 发行验收

| 流程 | 对齐验收 |
| --- | --- |
| 打开数据 | 检查 ROS1 bag、SLAM / EGO / SUPER 地图、点云累积和整图替换、Odometry 和 TF、速度话题、雷达当前帧、消息查看和 `.rviz` 导入及状态提示 |
| 回放和视角 | 像 RViz 一样选择 SLAM / EGO / SUPER 发布的 PointCloud2 地图话题，核对固定坐标系、累积与替换。检查机位、每层显隐、动态 TF 三轴、缩放、拖放与透明背景 |
| 规划图层 | 用 EGO 与 SUPER 示例分别检查计划轨迹、已飞轨迹、安全走廊、目标点、相机 FOV 和规划事件 |
| 素材和时间轴 | 用同一批点云、视频、图片和文字检查同步锚点、裁剪、删段、时间区间、事件跳转和撤销 |
| 画面合成 | 检查底片切换、平滑缩窗、透明背景和多路素材布局，核对同一时间的预览与导出 |
| 固定机位拖影图 | 检查框选、删帧与恢复、动态不透明度、重采样、背景合成和原分辨率 PNG 保存 |
| 项目往返 | 打开旧版 `.slamfpv`，核对素材引用、锚点、话题、图层样式和时间轴，再保存并重新打开 |
| 导出 | 检查透明 PNG、1080p/60 fps MP4、选定音轨和慢放，用同一项目核对画面和时间戳 |

已实现的原生点云回放、视角和里程计能力见 [原生预览说明](../native/README.md)。

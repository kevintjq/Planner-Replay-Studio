# Trajectory Studio 独立与批量画面导出

预览区域右上角相机按钮展开内联设置；`Ctrl+Shift+E` 保存当前完整画面。
选择像素尺寸、DPI 和边缘背景后，单帧支持 PNG/JPG/TIFF/PDF/SVG。
处理来源为完整解码视频或当前轨迹合成，不包含框选、时间轴和编辑控件。
输出配色独立于软件的亮色、深色或跟随系统模式。

## 批量操作

1. 打开视频并查看任意起始帧。导出累积轨迹图时，先完成框选、跟踪及编辑。
2. 展开相机设置中的 **Export Keyframes · 批量画面**。
3. 选择 **Source Frames · 源视频帧** 或 **Trajectory Snapshots · 累积轨迹图**。
4. 指定手动秒数、起止区间及间隔、采样网格序号，或当前轨迹采样帧。
5. 选择 PNG/JPG/TIFF，可选生成 PDF/SVG/PNG/TIFF 多联图和列数，然后选择输出父文件夹。

手动时间用逗号、空格或分号分隔；支持“添加预览时间”。采样网格的请求时间为
`序号 / Grid FPS`，并非原视频经过 PTS 认证的帧序号。当前轨迹采样帧使用真实跟踪时间。
每次最多 1000 张，排序并按纳秒去重。文件名模板支持 `{index}`、`{time}`、`{view}`，
禁止目录穿越、保留文件名或重复输出名。

累积轨迹图保留当前背景、采样、单帧透明度、排除区间和生成范围，按各请求时间裁切，
包含该时刻的有效帧，不绘制未来拖影或未来轨迹线。固定数量采样沿用当前编辑快照，
不会在每张图中重新分配采样位置。背景仍是生成轨迹时的固定机位底图。

## 时间及输出文件

所有时间均以该源视频的秒数为基准。源视频帧选择该时刻正在显示的已解码帧；例如
30 FPS 视频请求 1.25 秒可能选中 1.233333333 秒的帧。PNG 元数据和多联图标签记录
实际选中帧时间；累积轨迹图标签记录请求的裁切时间。

新建的 `trajectory-frames-日期-随机后缀` 子文件夹包含图片和原子更新的 `manifest.json`：

- `requested_time`：请求时间，也用于文件名中的 `{time}`。
- `output_time`：图片元数据/多联图标签时间。
- `source_frame_time`、`source_frame_index`：所选解码帧信息；累积轨迹图记录最近跟踪时间，
  未保存的原视频帧索引用 `-1` 明示。
- `sample_timestamps_ns`、`edits`、`opacity`：本次轨迹采样及编辑快照。
- `status`、`planned`、`completed`：完成、失败或取消，以及已保存文件。

导出在后台执行，预览及编辑快照保持。期间编辑和换源被锁定；取消后已完成文件保留，
正在编码的单张图片或多联图允许完成原子写入。项目恢复请求会先取消导出，再恢复项目。
缺失轨迹缓存会明确失败，避免静默漏掉无人机图像。

## 已知范围

尺寸 16–8192 像素，每张及多联图最多 4000 万像素，DPI 36–2400。
支持 1080P/2K/4K/8K 和自定义比例；源视频细节受原分辨率限制。
边缘背景不等同于移除视频背景。透明图片放在深色查看器上时，黑色文字可能不可见。

PDF/SVG 单帧仍嵌入位图；多联图编号与时间是真正的矢量文字，视频和轨迹合成是位图。
轨迹独立矢量线、该工作区的视角/图层拆分、科研事件接入、长批次性能以及精确源 PTS
仍待实现或验收。固定机位真实无人机前景跟踪验收单独追踪，源视频导出通过不代表跟踪通过。

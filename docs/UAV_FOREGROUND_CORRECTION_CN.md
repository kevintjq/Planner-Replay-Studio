# 无人机拖影图专项修正

来源：用户 2026-11-27 实测反馈。默认目标是干净背景上多个时间点、位置与姿态的同一无人机前景实例，轨迹线/标注仅是辅助。最终没有无人机即验收失败。此前需求全部继续有效。

## 立即排查及门禁

检查 C++ 采样、前景提取、alpha/mask、背景、裁剪/坐标映射、图层顺序、预览及最终导出是否复用同一结果。禁止只导出背景/轨迹/采样点；提取失败不能继续宣称拖影导出成功。仅用户显式选择“仅轨迹线”才可无前景。不得把整帧/整块 ROI 贴图冒充无人机提取，不得只改 UI。

## 完整管线

1. 同步视频的时间等间隔（最小 0.1 s）、距离、姿态、事件、手动选帧，单帧删除/恢复及多段排除。
2. 自动无人机前景、ROI、失败原因、逐帧蒙版、画笔/擦除、羽化、原图/蒙版/合成预览。
3. 视频参考帧、用户背景、配准结果；固定机位建模、轻微抖动对齐、背景亮度/对比度及阴影残留控制。
4. 多实例合成，自定义顺序/遮挡、全局与单帧透明度、实例缩放、显示全部/代表帧、显式跳过无效帧；边缘干净、合理姿态和位置，无人机为视觉主角。
5. 可选轨迹线、色映射/线宽/透明度、起终点、方向箭头、时间戳、编号、局部放大、比例尺、文字；前景设置独立于轨迹线设置，描边/阴影可选。
6. 预览及 PNG/PDF/SVG/TIFF/4K/8K 共用合成结果，不能漏前景、错误透明化/裁剪、过暗、位置错乱。矢量/位图如实说明。

## UI 与验收

Trajectory Studio 明确区分采样、无人机前景、背景、轨迹线。显示原始采样数、成功提取数、失败/过滤数和最终合成实例数；逐帧说明失败。最终导出前检查有效可见前景，禁止空结果冒充成功。

真实无人机视频实际 GUI 验收：固定机位多位置、抖动配准、时间采样、距离采样、手动删除、多段排除、提取失败跳过/提示、手动蒙版修正、轨迹与前景共同输出、仅前景、4K/8K、多个真实无人机实例可见。保存预览、最终图片、原始采样帧、前景 mask 与合成对比；报告上述四类数量。合成夹具只作回归，不能替代真实无人机素材验收。

全部使用 C++/Qt，可复用 OpenCV/ONNX Runtime C++，无 Python 应用运行依赖。修复优先于高级分析；动态 Display 等此前核心工作继续。

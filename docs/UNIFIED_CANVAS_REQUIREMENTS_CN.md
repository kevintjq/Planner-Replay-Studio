# 统一自由画布与科研制图增量需求

用户增量要求，2026-11-27。补充此前全部需求，不取消范围、不回滚有效代码；不能以编译或静态截图替代真实 GUI 验收。

## 共享引擎与独立工程状态

Video Editor 和 Trajectory Studio 共用 C++/Qt Canvas Engine、Layer Model、Transform、Selection、多选、Inspector、Appearance、Undo/Redo、Alignment/Snap、Rendering Pipeline、Export Engine。基础编辑只实现一次；两个工作区保持独立界面、图层实例、编辑状态和画布配置，互不干扰。

全部适用元素支持创建/删除、鼠标拖动、八手柄缩放、宽高比锁定、旋转、裁剪、复制/重命名、显隐/锁定、多选/分组、排序/置顶/置底、辅助线、边缘/中心吸附、精确数值及撤销/重做。画布、Layers、Inspector 双向实时同步。可以添加却无法删除、移动或缩放即失败。

## 外观与科研元素

共享透明/半透明/纯色背景、背景颜色/透明度、整体不透明度、边框颜色/线宽、圆角、阴影及文字描边。背景与内容透明度独立，默认轻量科研 HUD；输出样式不随应用亮暗主题强制改变。普通视频/照片去背景必须实际蒙版或前景提取，不能靠容器透明宣称去除。

共享元素库：文字/标题、PNG/JPG/SVG 图片、Logo、箭头、圆形、矩形、虚线框、引导线、比例尺、图例、Colorbar、局部放大、(a)/(b)/(c)/(d) 子图编号、速度表、曲线、自定义科研标注。均可增删、拖缩、旋转、排序及改样式。文字有字体/字号/字重/颜色/描边/阴影/对齐/中英文；图片保留 Alpha、可裁剪/替换/等比缩放。所有编辑非破坏性，原始科研素材只读。

## 拖影图、轨迹和端点

最终拖影图必须含多个真实无人机前景。保留最小 0.1 s、时间/距离/姿态/事件采样、单帧删除恢复、多段排除、全局/单帧透明度、自动提取、手动蒙版、背景配准、胶片带和双层时间轴。背景、每个前景、轨迹线、起终点、科研标注是独立图层或可编辑子对象。

轨迹线可增删/显隐，支持颜色、连续滑块和小数线宽、不透明度、实/虚/点线、渐变和按真实速度/时间/高度着色，可排在前景前后。轨迹来源必须真实或正确配准；改样式只重新绘制合成，不重新解码全部视频或提取前景。

起点默认绿色圆形，终点默认红色圆形，各自独立增删/显隐、直径、填充/透明度、实心/空心、描边/宽度；可仅显示圆，可配自定义文字、字号/颜色/位置。默认绑定有效轨迹真实起终点，可指定时间点；科研绑定位置与装饰圆应明确区分，防止自由拖动造成错误物理表达。

## 专业流程与复用

Video Editor 保留多轨剪辑、ROS/实拍同步、多视角/TF、多段显示、关键帧、渐变速度表、字幕音频、视频/B站制作。Trajectory 保留提取/多帧合成、轨迹/端点、采样排除、标注、多视图论文配图、出版模式、高清和矢量输出。

支持跨工作区复制适用文字/图片/速度表/图例/标注/样式；任意视频时刻完整画面转制图素材；拖影图添加至视频画布。能保留编辑能力时不强制展平位图。

左 Layers、中 Canvas、右动态 Inspector、底部对应视频/拖影时间轴，Apple 风格及双主题；常规下拉、滑块、折叠、内联编辑。

## 输出与性能

共用高质量离屏输出：完整画布、单层、多选层、任意帧、批量关键帧；PNG/PDF/SVG/TIFF；1080P/2K/4K/8K、自定义尺寸；300/600/1200 DPI；白/黑/透明/自定义底。轨迹、圆形、文字标注尽量真正矢量，前景视频可嵌位图。预览一致，默认无水印。

复用资源/图层/缓存。拖缩、文字、线宽、端点尺寸只更新必要状态；不得重载 Bag、全视频解码、全前景提取或重建全部资源。C++/Qt，无 Python 应用运行依赖。

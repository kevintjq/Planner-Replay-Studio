依据用户 2026-11-27 发行调整及 2026-11-28 RViz 验收收敛。本文件决定本次发行范围，优先于较早文档中
“全部高级功能完成后才可发布”的范围表述；旧需求继续追踪，不删除已验证代码。
目标调整为2026-11-28今晚23:00（按用户指定时间）。以必要核心流程可用为准，不以截止时间替代真实证据。

## 2026-11-28 最新验收收敛（优先于旧门禁表述）

停止穷尽和重复GUI测试，不再为非必要细节反复重构。四工作区各完成一条当前构建的必要
端到端流程，并复用未受改动影响的有效组件/文件证据：Visualization打开真实数据或空场景、
导入.rviz、编辑代表Display/属性、TF跟随及多视角；Synchronization核对准确PTS、时间偏移、
播放/跳转和真实速度；Video Editor完成画布编辑、时间轴、保存重开、视频及单帧输出；
Trajectory Studio完成真实无人机前景（允许明确标注手动蒙版修正）、排除/样式编辑和图片输出。
公共流程核对亮暗主题、关键控件可读性及编辑状态保全。

发行仍须当前最终包依赖完整、本机安装运行和安全同路径升级；崩溃、数据丢失、核心流程
失败、错误时间/输出及升级破坏是阻塞项。非阻塞UI细节、低风险边界、穷尽插件/属性/组合、
长时与全平台覆盖转用户安装后手测和后续PR。实际缺少的原始EGO/SUPER规划消息、逐生态
完整对照和原生多视角Alpha等边界继续标未验/限制，不冒充通过，也不再单独拉长本次穷尽验收。
不删除此前功能和长期需求，不扩大兼容声明。下表是产品范围与长期追踪，不能把其每个子项
或后文历史“完整/全部”措辞重新解释为本次逐项重复GUI前置条件。

2026-11-28 最新用户调整：干净 Windows 安装/运行由用户在正式发布后手动测试，不再作为
v1 发行前置门槛，不在 README 单列，也不为此寻找或准备 VM/新环境。验收责任与时间移交
不等于本机已经验证通过；相关未测证据保持 false。包内依赖完整、当前包本机实际运行、
安全同路径覆盖升级及其余核心门禁继续保留。

Windows 基础使用不强制 WSL、ROS 或 Python。不能将独立渲染子集表述为全部原生 RViz
插件兼容。原生默认插件、属性、实际数据、渲染和导出分别列矩阵；未实现/未验证/依赖缺失
明确列出。无数据、无 TF 或只构造了插件不能标记为渲染通过。

本次核心清单及官方配置依据见 [RViz 生态范围调整](V1_RVIZ_ECOSYSTEM_SCOPE_CN.md)：
Grid、Axes、Group、TF、PointCloud2、Odometry、Path、Marker、MarkerArray、Pose。
其中 Group 验收实例/嵌套/显隐及持久化，不要求不存在的传感器输出。其余原生默认/第三方插件可
保留“结构/属性/配置通过，真实渲染未验证”，转后续独立 PR，不单独阻塞 v1；不得借用核心
图像宣称全部33类渲染通过。本次保留可取得真实数据的代表对照及四工作区必要流程；
逐生态完整消息覆盖、全部GUI组合和边界验证按上文移交后续，画布/视频/单帧必要输出、
安装包依赖完整性及安全覆盖升级仍需实际验证。

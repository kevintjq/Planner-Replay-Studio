# v1.0.0 Core Release 范围与发行门禁

依据用户 2026-11-27 最新发行调整。本文件决定本次发行范围，优先于较早文档中
“全部高级功能完成后才可发布”的范围表述；旧需求继续追踪，不删除已验证代码。
目标为 2026-11-29（星期日）完成核心正式版，不以日期替代质量门禁，不承诺未经验证的交付。

Windows 基础使用不强制 WSL、ROS 或 Python。不能将独立渲染子集表述为全部原生 RViz
插件兼容。原生默认插件、属性、实际数据、渲染和导出分别列矩阵；未实现/未验证/依赖缺失
明确列出。无数据、无 TF 或只构造了插件不能标记为渲染通过。

## 正式发行条件

1. 核心矩阵每项有当前构建的实际 GUI、数据/渲染、保存恢复及输出证据；组件/编译不能替代。
2. 使用同 Bag/.rviz 与实际对应版本原生 RViz 对照，公开各平台/后端兼容差异及已知限制。
3. 真正未安装 WSL/ROS/Python 的干净 Windows 安装与核心流程通过；最小 PATH 仅为隔离检查。
4. 清理前检查 CMake/代码/CI/安装依赖，保护有效测试、许可、用户素材和历史迁移；清理后干净构建。
5. README 中英同步，品牌为 UAV Studio — All-in-One Robotics Research Studio；仓库 uav-studio、
   CMake 项目 UAVStudio、程序 uav-studio；真实截图、准确下载/安装说明及独立 Roadmap。
6. Conventional Commits；核心全部通过后才发布 v1.0.0、安装包、Release Notes 和真实素材。
   未通过时保持开发/预览标识，说明阻塞；新版本确认前保留必要旧发行版回退。

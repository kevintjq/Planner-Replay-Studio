## P0 无数据工作环境

1. 默认启动是真实空场景，显示基础 Grid、Axes、Displays、Inspector、相机工具；不自动载入模拟点云。
2. 不依赖 Bag/实时 ROS 即可按类型添加、删除、重命名、复制、分组和配置兼容 Display。
3. 数据源与实例生命周期独立；更换/移除数据源保留显示配置、相机与画布。
4. 无数据保持属性可编辑，有 Topic 的 Display 显示 Waiting for Data / No Data。
5. By Topic 使用真实目录；无目录时允许手动输入 Topic。未知消息仍可浏览，不伪造兼容渲染。
6. .rviz 可在数据源/可选原生运行库就绪前导入、尽可能编辑和保存；未知属性/插件原文保留并报告。
7. 工具从实际后端发现。原生 Move Camera / Select / Focus / Measure 等仅在实际可用并正确处理事件时启用。
8. 保留 Orbit/FPS/Top-down/TF Follow 等适用视角及既有自定义相机能力；未支持的部分明确记录。
9. 无 Bag 同样可添加素材并布局；缺数据的速度表显示 N/A；模拟模式必须由用户主动选择。

## Windows 独立发行

Windows 基础功能不强制依赖 WSL、Ubuntu、ROS 或 Python。C++/Qt 独立后端始终可用。
原生 RViz/第三方插件是可选增强；自动检测、后台启动、连接/重连，脚本和发行版覆盖仅放高级设置。
检测失败只影响相应增强能力，不应导致基础编辑失效。安装包仅包含可合法分发的必要运行库。
分别记录独立后端、各 ROS/RViz 原生版本的全部差异，不能用自定义子集宣称完整原生兼容。
安装包须包含完整依赖，并完成本机实际安装/运行与安全覆盖升级。真正未装WSL/ROS/Python的
干净Windows安装/运行由用户正式发布后手测，不再阻塞v1，不继续寻找或准备VM/环境。
最小PATH只证明进程依赖隔离；责任移交不代表本机已通过该环境测试。

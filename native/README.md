# Planner Replay 原生预览

原生预览从源码构建。日常使用请下载完整工作台。见[安装和使用说明](../README_CN.md)。

## 项目兼容

可从「打开项目」加载现有 `.slamfpv`，预览模拟数据或项目引用的 ROS1 点云。另存会重新计算素材相对路径，并保留尚未迁移的项目设置。点击「打包」可将录包、视频、图片和外参复制进新文件夹，然后在移动后继续打开 `project.slamfpv`。

## 操作

- 打开 ROS1 bag，选择 `PointCloud2` 和 `Odometry` 话题。支持配准点云，以及里程计机体坐标系中的点云。后者需要同步位姿。
- 点击播放或拖动时间轴。左键旋转视口，右键平移，滚轮缩放。距离颜色以当前机体位置为基准。
- 主视口可切换地图总览、前后左右跟随、高低位、环绕、稳定 FPV 和原始 FPV。主视角随项目保存。可添加附加点云机位，在画面拖动位置并编辑大小、缩放和叠加内容。
- 在「当前扫描设置」选择 PointCloud2、LaserScan 或 Livox CustomMsg 话题，设置最大保留时间。选择主点云话题时，高亮最新一帧。
- 在「缩窗动画」选择主点云、附加机位、实拍、图片、文字或速度表。设置放大区间的起点、位置、宽度和缩窗时长后，将播放头移到缩窗时刻并添加标记。动画随项目保存。
- EGO 和 SUPER 的常见占据地图话题默认整图替换。可从 Odometry 或 TF 读取位姿，并选用独立 Twist、TwistStamped 或 Odometry 速度话题。旧项目引用的外参 JSON 也会用于坐标变换。
- bag 支持无压缩、BZ2 和 LZ4。预览版每块最多 256 MiB，每个所选点云话题最多载入 1600 万有效点，不做自动降采样。

原生回放会识别 EGO 的 B 样条和 SUPER 的可视化轨迹、走廊与目标点话题。可在左侧显隐这些图层，并通过事件列表跳转到计划发布与目标更新时间。

### 实拍预览

左侧「实拍视频」可同时导入多段素材。选择素材后设置视频入点、出点和偏移。需要校正两个机位的时钟漂移时，分别暂停在回放中的两个共同事件，并输入该机位中同一事件的时间作为锚点。「另存为」保留这些设置。

打开旧项目后，视频预览读取保存的时间裁剪、画面裁剪、锚点和保留片段。每路视频在时间轴上各占一行。拖动片段边缘可裁剪，拖动未被视图边界截断的片段可移动其保留区间。可在播放头处或通过片段右键菜单分割和删段。撤销和重做支持时间裁剪、锚点和片段编辑。保存项目后重新打开可继续编辑。

当前使用点云回放驱动视频小窗。

### 布局切换

暂停后在「布局切换」选当前合成、实拍全屏、点云全屏、实拍底片或实拍小窗。实拍布局使用左侧选中的视频。可设定从底片缩成小窗的过渡时间，也可通过布局列表跳转或移除标记。原生预览会读取旧项目中的底片大小和位置。

### 图片与文字

用左侧「图片与文字」添加叠加素材，设置出现时间、图片宽度、文字字号和颜色。可在预览中直接拖动素材，也可以从时间轴裁剪显示区间。图片和文字的位置、样式与区间会随项目保存。时间轴可在当前播放位置添加、跳转、重命名和删除手动标记。

### RViz 配置

点击「导入 RViz 配置」打开 `.rviz`、`.yaml` 或 `.yml`。原生预览使用配置里的话题、颜色和启用状态。展开「RViz 话题显示」即可显隐各图层，另存后会保留配置。当前可叠加 PointCloud2、LaserScan、Path、Marker / MarkerArray、位置消息和 TF 坐标轴。原生回放按消息时间应用录包内的静态和动态 TF。配置所需的固定坐标系有完整覆盖时，主点云也会转换到该坐标系。状态栏会提示找不到话题、消息类型不受支持或 TF 覆盖不足的显示项。

### 话题查看

通过「话题查看」选择录包中的任意话题，读取播放位置之前最近的一条消息。可查看和复制自定义字段，检查常见 ROS 图像的像素预览。长数组显示总项数及开头 128 项，无法解析的类型显示原始字节摘要。

### 导出当前帧

暂停在需要的画面，点击「导出当前帧 PNG」。启用「透明画布」可保留透明背景。输出使用当前预览视口的尺寸，包含可见点云、视频和图片文字图层。

### 固定机位拖影

打开「固定机位拖影」，选择视频和起始帧，在画面上拖动框选无人机，然后点击「生成拖影」。可设结束时间，留空时跟踪至视频结束或丢失目标。采样间隔设为 0 时按画面中的移动距离选择帧。采样帧列表支持单独删除与恢复，不透明度和采样间隔可直接调整。保存的 PNG 使用素材的原始分辨率。

### 速度表与导出视频

在「显示合成速度表」设置量程、显示区间、缩放及背景。速度表可以在预览画面拖动，也会出现在导出的视频中。

在「导出视频」选择开始、结束、速度与音轨。MP4 输出为 1920 × 1080、60 fps。支持 1×、0.5× 和 0.25×，可选择一路实拍原声。视频逐帧使用项目时刻解码和合成，音频应用相同的同步锚点、保留片段与速度。需要 FFmpeg（含 libx264）与 FFprobe，可放在程序目录或 PATH 中。

## 构建

需要 CMake 3.22、支持 C++20 的编译器、Qt 6.8 或更高版本（含 Qt Multimedia），以及 BZip2、LZ4、yaml-cpp 和含 tracking、videoio 的 OpenCV 4.8 或更高版本。在 Windows 上可通过 vcpkg 的 `x64-windows-static-md` 安装压缩库。生成安装包还需要 NSIS。构建和安装测试命令见 [Windows 构建流程](../.github/workflows/native-windows.yml)。

`PlannerReplayCli inspect recording.bag` 输出 JSON，包含话题类型、消息数量、录制时间范围和 TF 坐标系关系。Windows 安装后可在安装目录的 `app` 文件夹运行。

命令行可复用桌面版合成设置。导出时会打开渲染窗口，完成后自动退出。

```sh
PlannerReplayCli export project.slamfpv --start 1.5 --output still.png
PlannerReplayCli export project.slamfpv --start 1.5 --seconds 4 --output flight.mp4
PlannerReplayCli bag recording.bag --start 0 --seconds 3 --output preview.mp4
PlannerReplayCli demo --start 0.5 --output demo.png
```

MP4 的播放速度和音轨使用项目设置，时间参数以回放秒数为单位。省略 `--seconds` 时导出到录制结束。

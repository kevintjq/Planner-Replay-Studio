# UAV Studio 原生预览

原生应用使用 C++ / Qt；当前正式版及安装说明见[中文指南](../README_CN.md)，实际验证范围见[验收矩阵](../docs/REBUILD_ACCEPTANCE_CN.md)。源代码能力不等于全部配置均已通过验收。安装包保留本指南的 `native/README.md` 层级，离线入口为 `app/README.md` 与 `app/README_CN.md`。

### 外观与工作区

顶部 Appearance 提供 Light、Dark、System，自动保存偏好。四个工作区使用统一语义颜色和公共控件，切换主题复用已加载录包、画布及三维对象。场景背景、速度表输出方案和导出背景独立设置。普通设置放在 Inspector；浮动时间轴仍可由用户主动开启。Topic 和 TF Frame 下拉框支持搜索，Frame 来自录包的真实 TF 树。当前更改主要数据话题/Fixed Frame 仍会重新加载录包；完整原生后端与主画布的边界见下文。

## 项目兼容

新项目默认保存为 `.uavstudio`，可继续打开现有 `.slamfpv`。另存会重新计算素材相对路径，并保留尚未迁移的项目设置。点击「打包」可将录包、视频、图片和外参复制进新文件夹；打包内部文件名 `project.slamfpv` 为历史兼容，继续可打开。

## 操作

- 打开 ROS1 bag，选择 `PointCloud2` 和 `Odometry` 话题。支持配准点云，以及里程计机体坐标系中的点云。后者需要同步位姿。
- 点击播放或拖动时间轴。独立渲染主视口左键旋转，中键或 Shift 拖动平移，右键拖动或滚轮缩放；附加视角的右键/中键拖动用于平移。原生 RViz 使用当前原生相机工具的交互。距离颜色以当前机体位置为基准。
- 主视口可切换地图总览、前后左右跟随、高低位、环绕、稳定 FPV 和原始 FPV。主视角随项目保存。可添加附加点云机位，在画面拖动位置并编辑大小、缩放和叠加内容。
- 主/附加相机支持 Target Frame、位置/航向/完整姿态跟随、滞后和平滑、光学轴、点大小与独立颜色/显隐；同一预设允许添加多个视角。显式目标缺少 TF 会显示诊断，不改用其他位姿冒充跟随。参数和独立视角随项目保存，普通编辑不重读 Bag。
- 在「当前扫描设置」选择 PointCloud2、LaserScan 或 Livox CustomMsg 话题，设置最大保留时间。选择主点云话题时，高亮最新一帧。
- 在「缩窗动画」选择主点云、附加机位、实拍、图片、文字或速度表。设置放大区间的起点、位置、宽度和缩窗时长后，将播放头移到缩窗时刻并添加标记。动画随项目保存。
- EGO 和 SUPER 的常见占据地图话题默认整图替换。可从 Odometry 或 TF 读取位姿，并选用独立 Twist、TwistStamped 或 Odometry 速度话题。旧项目引用的外参 JSON 也会用于坐标变换。
- bag 支持无压缩、BZ2 和 LZ4。预览版每块最多 256 MiB，每个所选点云话题最多载入 1600 万有效点，不做自动降采样。

Windows 独立回放会识别 EGO 的 B 样条和 SUPER 的可视化轨迹、走廊与目标点话题。可在左侧显隐这些图层，并通过事件列表跳转到计划发布与目标更新时间。

### 实拍预览

左侧「实拍视频」可同时导入多段素材。选择素材后设置视频入点、出点和偏移。需要校正两个机位的时钟漂移时，分别暂停在回放中的两个共同事件，并输入该机位中同一事件的时间作为锚点。「另存为」保留这些设置。

打开旧项目后，视频预览读取保存的时间裁剪、画面裁剪、锚点和保留片段。每路视频在时间轴上各占一行。拖动片段边缘可裁剪，拖动未被视图边界截断的片段可移动其保留区间。可在播放头处或通过片段右键菜单分割和删段。撤销和重做支持时间裁剪、锚点和片段编辑。保存项目后重新打开可继续编辑。

视频小窗由主实验时间轴驱动，在工作线程使用与导出相同的 FFmpeg 解码器，按实际 PTS 选择帧，暂停时准确落帧。非零源起点、变帧率及 B 帧不通过平均 FPS 估算。连续预览允许临时呈现少量滞后的已完成帧；导出重新解码准确的完整质量画面。时间定义和限制见[PTS 同步说明](../docs/PRECISE_VIDEO_SYNC_CN.md)。

### 布局切换

暂停后在「布局切换」选当前合成、实拍全屏、点云全屏、实拍底片或实拍小窗。实拍布局使用左侧选中的视频。可设定从底片缩成小窗的过渡时间，也可通过布局列表跳转或移除标记。原生预览会读取旧项目中的底片大小和位置。

### 图片与文字

用左侧「图片与文字」添加叠加素材，设置出现时间、图片宽度、文字字号和颜色。可在预览中直接拖动素材，也可以从时间轴裁剪显示区间。图片和文字的位置、样式与区间会随项目保存。时间轴可在当前播放位置添加、跳转、重命名和删除手动标记。

### RViz 配置

已配置图层的开关直接作用于共享渲染器，保留播放、相机、标记及编辑状态。初次读取时也会缓存隐藏图层的数据，因而重新启用不需重读 Bag；大型配置的加载内存仍待量化。同一 RViz TF 节点的动态/静态层联动。关闭全部已配置点云不会重新显示默认点云。添加新配置、更改主要数据源或 Fixed Frame 仍会读取 Bag。

点击「导入 RViz 配置」打开 `.rviz`、`.yaml` 或 `.yml`。Windows 独立预览使用配置里的话题、颜色和启用状态。展开「RViz 话题显示」即可显隐各图层，另存后会保留配置。当前可叠加 PointCloud2、LaserScan、Path、Marker / MarkerArray、位置消息和 TF 坐标轴。独立回放按消息时间应用录包内的静态和动态 TF。配置所需的固定坐标系有完整覆盖时，主点云也会转换到该坐标系。状态栏会提示找不到话题、消息类型不受支持或 TF 覆盖不足的显示项。

新导入配置的完整原文、嵌套分组、未知插件及属性现在保存在项目里；兼容说明明确列出未按原插件渲染的项目。点击「Export RViz」可导回 `.rviz`：没有编辑时保留原始字节和 UTF-8 BOM，有编辑时只更新已支持的显示字段及 Fixed Frame，保留 Topic QoS、相机、工具等其他内容；重新序列化可能改变注释和格式。Windows 独立渲染路径仍是有限子集，未知属性保留不代表运行了原生librviz插件或编辑器。UAV 专用图层过滤及视角布置不冒充标准 RViz 属性。禁用父分组与拆分 TF 的冲突会明确拒绝导出；旧项目之前已经丢失的原配置需重新导入，不能凭空恢复。

左侧「Native RViz」连接独立的真实 ROS1 Noetic / Qt5 / librviz 后端，左侧树与右侧 Inspector 共用原生属性模型，支持实际插件枚举、By Type/By Topic、Topic/Frame 选项、范围/状态、Display 操作及原生 `.rviz` 保存。Windows 通过已安装 ROS 环境的 WSL 运行；含 ELF 的开发包提供相邻启动器，缺少外部 ROS/图形环境会明确报错。构建/依赖及验收边界见[原生后端说明](../docs/NATIVE_RVIZ_BACKEND_CN.md)。

加载真实 Bag 后，可在该 Inspector 点击「索引实验时间」，按列出的实际话题建立 Header 索引；零/缺失时间戳不会偷偷按录包写入时间处理。暂停同步和反向跳转恢复消息历史及 TF。原生主视角已接入主画布及准确时刻渲染通路；完整 GUI、视频/图片合成、多视角和性能门禁仍未全部验收。严格历史回放预览上限为 4 Hz，不能宣称实时 30 fps；也不能把独立渲染子集的导出结果当成全 RViz 插件输出。逐插件结构、实际数据与渲染证据分别列在[兼容矩阵](../docs/RVIZ_COMPATIBILITY_MATRIX_CN.md)。

### 话题查看

通过「话题查看」选择录包中的任意话题，读取播放位置之前最近的一条消息。可查看和复制自定义字段，检查常见 ROS 图像的像素预览。长数组显示总项数及开头 128 项，无法解析的类型显示原始字节摘要。

### 导出当前帧

在 Visualization 或 Video Editor 的预览右上角点击相机，Inspector 展开导出设置；Ctrl+Shift+E 快速保存。支持完整画布、单独三维视角、选中图层，输出 1080P/2K/4K/8K 或自定义宽高、36–2400 DPI（含 300/600/1200 预设），PNG/JPG/TIFF/PDF/SVG，以及透明、白、黑或自定义背景。独立开启文字和速度表；画布编辑边框与操作控件不进入文件。当前已存在的三维/视频/图片/文字合成复用共享渲染器；尚未实现的科研曲线、标尺等不能视为已支持。

点云 FBO 按实际输出尺寸重新创建，视频使用完整源帧，不放大窗口截图。保存完成恢复播放头和播放状态。GPU 上限会提前报错；尚未初始化的三维上下文会先异步准备，失败时明确停止并恢复编辑状态。当前单边最多 8192、最多 4000 万像素，尚无分块渲染。Visualization/Video Editor 的 PDF/SVG 场景合成仍嵌入位图；Trajectory Studio 的适用轨迹、端点、文字和科研图形可保留真正矢量，背景、无人机视频帧、点云及原生场景使用位图。不同导出通路的能力不能互相代替，也不声称完整画布是纯矢量。

批量关键帧支持手动秒数、区间间隔、事件标记及指定采样网格序号。采样网格时间为序号除以指定 FPS，不等同视频原始 PTS。选择 All Views Separately 可按时间逐个导出主视角和附加视角。每批创建独立目录，`manifest.json` 记录实际实验时间、视角、设置、完成/失败/取消状态和 FBO 尺寸；默认文件名 `frame_{index}_{time}_{view}`，支持三个占位符，拒绝路径穿越和重名，最多 1000 张。

可同时生成多联图，统一面板尺寸和输出设置，自动添加 (a)、(b)… 和实验时间。PDF/SVG 的子图编号与时间戳是真实矢量文字，场景面板嵌入为位图。多联图总计最多 4000 万像素；当前尚不提供色标/物理比例尺锁定与独立面板高级设置。取消时保留已完成图片及清单。

Trajectory Studio 相机入口可独立保存当前源画面或轨迹合成，重新按完整质量源素材及最新编辑快照渲染，支持相同分辨率、DPI 和文件格式。源视频/累积轨迹图支持手动时间、区间、采样网格、实际轨迹采样、批量、多联图及取消清单。源视频位图细节受原始分辨率限制；背景设置填充画布边缘，不自动抠除视频背景。该工作区的独立视角/图层拆分和完整科研事件仍待补齐。

真实录包和视频已检查 4K/8K FBO、alpha、DPI、主题无关输出、批量与取消恢复。精确 PTS 解码后，1080P/4K 各 3 个对应时间点的图片与视频编码前画面再次逐像素一致；实际 MP4 为 YUV420，会有色度采样差异，已另做解码对照。长导出、真实多机位漂移、完整手动 GUI 与性能目标尚未认证。

### 固定机位拖影

打开 Trajectory Studio，选择固定机位视频和起始帧，拖动框选无人机后点击「生成拖影」。结束时间留空时跟踪至结束或丢失目标。采样提供固定间隔（最低 0.1 秒）、固定数量、仅手动与原有自动间距；自动间距是图像间距，不能作为物理距离。虚拟列表和缩略图缓存支持多选、单帧 alpha、手动添加、分段排除、生成范围和撤销/重做。轨迹线与无人机帧可分别排除；半开区间按纳秒时间稳定记录，随项目保存。原有「保存 PNG」继续以原分辨率输出。

### 速度表与导出视频

在「显示合成速度表」设置量程、显示区间、缩放及背景。速度表可以在预览画面拖动，也会出现在导出的视频中。

在「导出视频」选择开始、结束、速度与音轨。MP4 默认 1920 × 1080、60 fps，可按导出设置提高至 4K。支持 0.25×、0.5×、1×、2× 和 4×，可选择一路实拍原声。视频逐帧使用完整源帧与输出尺寸的实际点云 FBO，包含附加视角，并与图片共用离屏管理；画布背景不强制覆盖视角的透明设置。完成或取消后恢复原播放头、播放状态和捕获设置。音频应用相同的同步锚点、保留片段与速度。需要 FFmpeg（含 libx264）与 FFprobe，可放在程序目录或 PATH 中。

## 构建

需要 CMake 3.22、支持 C++20 的编译器、Qt 6.8 或更高版本（含 Qt Multimedia、Qt SVG 和 TIFF 插件 qtimageformats）、FFmpeg 开发/共享包（libavformat、libavcodec、libswscale、libavutil），以及 BZip2、LZ4、yaml-cpp 和含 tracking、videoio 的 OpenCV 4.8 或更高版本。Windows 使用 `-DFFmpeg_ROOT=...` 指定含 include/lib/bin 的共享包；编译和部署须使用相同 ABI DLL。在 Windows 上可通过 vcpkg 的 `x64-windows-static-md` 安装压缩库。生成安装包还需要 NSIS。构建和安装测试命令见 [Windows 构建流程](../.github/workflows/native-windows.yml)。

Windows 打包先将当前构建用 `cmake --install` 安装到新的 staging 目录，再调用
`native/installer/package.ps1`。部署前只接受两个产品程序及所选 FFmpeg 包中哈希一致的DLL；
Qt/OpenCV/CRT、说明和许可由打包脚本随后加入。旧部署目录、旧codec、测试程序、媒体或其他
残余会导致明确拒绝，脚本不会自动删除文件；重新打包或部署中断后使用新的 staging 目录。
`native/tools/test-windows-staging-input.ps1` 和 `check-windows-packaging.ps1` 可在不运行主程序的
情况下检查输入保护与源码/资源清单，不能替代新安装包运行验收。

安装器暂不支持原位置自动升级。目标位置已有 `app` 或 `Uninstall.exe` 时，会在写入任何
应用文件、快捷方式或注册信息前拒绝；请选择新的安装文件夹，旧安装及额外文件保留。
这一保护不等于版本迁移或清单式卸载已实现。新包包含所选 Qt 发行包的官方
`qoffscreen.dll`，其许可证随 Qt 一并提供。Windows 实测该平台使用软件后端，无法初始化
CloudView 所需的三维上下文；它只适合相应二维 smoke，不能替代真实 Windows/OpenGL 导出。
`new-package-runtime-check.ps1 -Offscreen` 先检查该插件，再隔离安装并在最小 PATH 下运行
smoke；包含 CloudView 的导出可能明确失败，不能把插件存在当作三维验收通过。
真实 GPU 启动、可见 GUI、安装包依赖完整及安全覆盖升级仍为独立门禁。

`uav-studio-cli inspect recording.bag` 输出 JSON，包含话题类型、消息数量、录制时间范围和 TF 坐标系关系。Windows 安装后可在安装目录的 `app` 文件夹运行。

命令行可复用桌面版合成设置。导出时会打开渲染窗口，完成后自动退出。

```sh
uav-studio-cli export project.slamfpv --start 1.5 --output still.png
uav-studio-cli export project.slamfpv --start 1.5 --seconds 4 --output flight.mp4
uav-studio-cli bag recording.bag --start 0 --seconds 3 --output preview.mp4
uav-studio-cli demo --start 0.5 --output demo.png
uav-studio-cli rviz-roundtrip original.rviz --output restored.rviz
```

MP4 的播放速度和音轨使用项目设置，时间参数以回放秒数为单位。省略 `--seconds` 时导出到录制结束。

`rviz-roundtrip` 在 C++ 项目中保存并重开配置后导出，输出 JSON 说明逐字节一致性、显示数量及未原生渲染插件，禁止覆盖输入文件。

可选的真实 RViz 配置验收工具在 `native/tools/rviz-probe`。它单独使用 ROS Noetic / Qt5；不进入 Qt6 主程序或 Windows 安装包依赖。已有 Noetic 开发环境中 source 设置后，通过独立 CMake 工程编译 `rviz-config-probe`，输入配置路径和输出前缀；工具核对 RViz 实际显示树，保存截图及 RViz 自身另存结果。该检查不等于录包播放或三维场景对照通过。

在已安装 ROS1 Noetic 的 Linux 端，可编译 C++ 点云发送端。先启动接收端，再启动发送端。

```sh
source /opt/ros/noetic/setup.bash
cmake -S examples/ros1-native -B build-ros-relay
cmake --build build-ros-relay --parallel
uav-studio-cli listen --seconds 6 --output flight.mp4
# 在另一个终端
./build-ros-relay/planner_replay_bridge
```

发送端需要 ROS1 的 roscpp、topic_tools 和 Qt 5 开发包。两端默认使用本机 8765 端口。接收完成后由原生工作台导出。

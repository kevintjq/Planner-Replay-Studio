# Planner Replay 原生预览

原生预览从源码构建。日常使用请下载完整工作台。见[安装和使用说明](../README_CN.md)。

## 项目兼容

可从「打开项目」加载现有 `.slamfpv`，预览模拟数据或项目引用的 ROS1 点云。另存会重新计算素材相对路径，并保留尚未迁移的项目设置。点击「打包」可将录包、视频、图片和外参复制进新文件夹，然后在移动后继续打开 `project.slamfpv`。

## 操作

- 打开 ROS1 bag，选择 `PointCloud2` 和 `Odometry` 话题。支持配准点云，以及里程计机体坐标系中的点云。后者需要同步位姿。
- 点击播放或拖动时间轴。左键旋转视口，右键平移，滚轮缩放。距离颜色以当前机体位置为基准。
- EGO 和 SUPER 的常见占据地图话题默认整图替换。速度读自里程计的三维线速度。
- bag 支持无压缩、BZ2 和 LZ4。预览版每块最多 256 MiB，每个所选点云话题最多载入 1600 万有效点，不做自动降采样。

本版覆盖原生点云回放。独立速度话题、通用 TF 树、规划及走廊图层、实拍合成和 60 fps 导出可在 [视频合成工作台](https://github.com/kevintjq/Planner-Replay-Studio/blob/main/docs/studio.zh-CN.md) 使用。

### 实拍预览

左侧「实拍视频」可同时导入多段素材。选择素材后设置视频入点、出点和偏移。需要校正两个机位的时钟漂移时，分别暂停在回放中的两个共同事件，并输入该机位中同一事件的时间作为锚点。「另存为」保留这些设置。

打开旧项目后，视频预览读取保存的时间裁剪、画面裁剪、锚点和保留片段。每路视频在时间轴上各占一行。拖动片段边缘可裁剪，拖动未被视图边界截断的片段可移动其保留区间。可在播放头处或通过片段右键菜单分割和删段。撤销和重做支持时间裁剪、锚点和片段编辑。保存项目后重新打开可继续编辑。

当前使用点云回放驱动视频小窗，音轨合成、布局事件及视频导出仍在迁移中。

### 图片与文字

用左侧「图片与文字」添加叠加素材，设置出现时间、图片宽度、文字字号和颜色。可在预览中直接拖动素材，也可以从时间轴裁剪显示区间。图片和文字的位置、样式与区间会随项目保存。时间轴可在当前播放位置添加、跳转、重命名和删除手动标记。

### RViz 配置

点击「导入 RViz 配置」打开 `.rviz`、`.yaml` 或 `.yml`。原生预览使用配置里的话题、颜色和启用状态。展开「RViz 话题显示」即可显隐各图层，另存后会保留配置。当前可叠加与主点云坐标系一致的 PointCloud2、LaserScan、Path 和位置消息。其他显示项和指定的固定坐标系会保存在项目中。状态栏会提示话题、消息类型或坐标系不匹配的项目。

## 构建

需要 CMake 3.22、支持 C++20 的编译器、Qt 6.8 或更高版本（含 Qt Multimedia），以及 BZip2、LZ4 和 yaml-cpp。在 Windows 上可通过 vcpkg 的 `x64-windows-static-md` 安装压缩库。生成安装包还需要 NSIS。构建和安装测试命令见 [Windows 构建流程](../.github/workflows/native-windows.yml)。

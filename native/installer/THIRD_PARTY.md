# Third-party software

- Qt 6.8.3 is dynamically linked. The Qt libraries and plugins are distributed under the GNU Lesser General Public License v3. License texts are in the `licenses` directory. The [corresponding Qt sources](https://download.qt.io/archive/qt/6.8/6.8.3/single/) are available from the Qt archive. The installed Qt DLLs may be replaced with compatible modified builds.
- OpenCV 4.10.0 and its FFmpeg video I/O plugin are shipped as DLLs. See the bundled OpenCV and FFmpeg licenses. The [OpenCV source](https://github.com/opencv/opencv/tree/4.10.0), [contrib source](https://github.com/opencv/opencv_contrib/tree/4.10.0), and [video I/O plugin source](https://github.com/opencv/opencv/tree/4.10.0/modules/videoio/src) are available from OpenCV.
- FFmpeg 7.1.1 shared libraries provide source PTS decoding, and FFmpeg/FFprobe executables provide encoding and inspection. The selected Gyan full shared build is GPL v3; its license is bundled as `licenses/FFmpeg.txt`. `FFmpeg-build-README.txt` retains the distributor's exact source commit and build notes; `FFmpeg-version.txt` and `FFmpeg-buildconf.txt` record the shipped binary's version and configuration. Its [fixed build package](https://github.com/GyanD/codexffmpeg/releases/tag/7.1.1) and the [corresponding FFmpeg 7.1.1 sources](https://ffmpeg.org/releases/ffmpeg-7.1.1.tar.xz) identify the dependency version. Distribution must retain the applicable GPL notices and corresponding source/build information for the shipped build.
- BZip2, LZ4 and yaml-cpp notices are in the `licenses` directory.
- The Microsoft Visual C++ runtime files are included from the Visual Studio redistributable directory.
- An optional `rviz_host` directory contains the project's Linux x86_64 native RViz host, launcher, MIT license and rebuild sources. This ELF requires a compatible Ubuntu 20.04 / ROS Noetic / RViz / Qt5 / OGRE environment supplied separately; the Windows application starts it through the configured WSL distribution. It is not a Windows-native plugin bundle or an included ROS installation. See `rviz_host/README.md`, `README_CN.md` and `backend.json`.
